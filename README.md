# flex-work-hours-pacer

[flex.team](https://flex.team) 근무 페이지(`내 근무` > `my-work-record`)에서, 이번 정산기간에 하루 평균 얼마나 더 일해야 하는지를 계산해서 화면에 바로 보여주는 Firefox/Chrome 브라우저 확장 프로그램입니다.

`133:03` 실근무시간 위젯 바로 아래에 `Need Xh Ym/day (Nd)` 형태로 작게 표시됩니다. 괄호 안은 남은 근무일수로, 계산이 조용히 틀렸을 때 눈으로 바로 확인하기 위한 값입니다.

## 어떻게 계산하나요

- **잔여 필수 근무시간**: 근무 위젯에 표시되는 값(예: `-36:03`)을 그대로 사용합니다.
- **남은 근무일수**: 캘린더에서 **오늘(포함)부터 정산기간 종료일까지, 아직 근무가 필요한 날**을 셉니다. 아래 세 조건 중 하나라도 걸리면 제외합니다.
  1. **주말** — 셀의 요일 문자(`토`/`일`)로 판정하므로 CSS와 무관하게 항상 제외됩니다.
  2. **공휴일** — 셀에 붙는 `colorType-holiday` variant 클래스로 판정합니다 (예: 광복절 대체공휴일).
  3. **근무시간 칩에 이미 시간이 들어있는 날** — 그 시간은 위젯의 실근무/잔여 필수 시간에 이미 반영되어 있으므로, 잔여 시간을 다시 배분받으면 안 됩니다. 지난 근무일(예: `7:57`)과 **아직 오지 않은 연차**가 여기에 해당합니다. flex.team은 예정 연차를 실근무시간에 미리 얹기 때문에, 미래의 연차 날도 칩이 `8:00`으로 채워집니다.
  - **예외 — 근무 중인 오늘**: 오늘 셀에 `boxType-realtimeWorkActive` 마커가 붙어 있으면(= 근무 중) 오늘 근무는 아직 미확정이므로 칩 값과 무관하게 포함합니다. 진행 중 근무는 실근무에 반영되지 않고 퇴근 후에 칩이 채워지므로, 퇴근하는 순간 오늘은 자동으로 제외됩니다.
- **하루 평균 필요시간** = 잔여 필수 근무시간 / 남은 근무일수

칩 기반 규칙이라 연차를 등록해도 페이스가 흔들리지 않습니다. 연차 5일을 넣으면 잔여 필수가 40시간 줄고 분모에서도 5일이 빠져, 하루 필요시간은 그대로 유지됩니다(분모만 그대로 두면 하루 2시간 이상 과소평가됩니다).

페이지 마크업이 바뀌어 필요한 값을 못 찾으면 아무것도 표시하지 않고 콘솔에 경고만 남깁니다(잘못된 숫자를 보여주지 않기 위함). 캘린더의 일요일 셀에 휴일 클래스가 하나라도 안 붙어 있으면 휴일 정보가 아직 로드되지 않은 상태로 보고 같은 정책을 적용합니다. 공휴일이 근무일로 잡혀 하루 필요시간이 과소평가되는 것이 가장 위험한 실패 모드이기 때문입니다.

자세한 설계는 [`docs/superpowers/specs`](docs/superpowers/specs), 구현 계획은 [`docs/superpowers/plans`](docs/superpowers/plans)를 참고하세요.

## 설치 (개발자 모드로 로컬 로드)

이 저장소는 스토어에 배포하지 않고, 로컬에서 직접 로드해서 사용하는 걸 전제로 합니다.

### Firefox

1. `about:debugging#/runtime/this-firefox` 접속
2. **"임시 부가 기능 로드..."** 클릭
3. 이 저장소의 `manifest.json` 파일 선택

### Chrome

1. `chrome://extensions` 접속
2. 우측 상단 **"개발자 모드"** 켜기
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭 → 이 저장소 폴더 선택

두 브라우저 모두 임시/개발자 모드 로드이므로, 브라우저를 재시작하면 다시 로드해야 합니다.

## 개발

순수 계산 로직(`src/pace.js`)은 Node.js 내장 테스트 러너로 테스트합니다. 외부 의존성은 없습니다.

```bash
npm test
```

`src/content.js`는 실제 flex.team 페이지 DOM에 의존하는 부분이라 자동화 테스트 없이, 브라우저에 로드해서 수동으로 확인합니다.

## 파일 구조

```
manifest.json     확장 프로그램 매니페스트 (Manifest V3)
src/
  pace.js         잔여 시간/남은 근무일/하루 평균 계산 (테스트됨)
  content.js      페이지 DOM에서 값 추출 + 화면에 표시
  banner.css      표시 스타일
test/
  pace.test.js    pace.js 테스트
```

## 알려진 제한사항

- 정산기간이 한 달(달력 뷰 한 화면)을 벗어나는 경우는 지원하지 않습니다.
- flex.team의 CSS 클래스명은 해시 기반이라 배포마다 바뀔 수 있어, 가능한 한 `data-scope`/`data-part` 속성과 텍스트 패턴에 의존하도록 만들었지만 페이지 구조가 크게 바뀌면 동작하지 않을 수 있습니다. 휴일/근무중 판정은 해시 접두어를 무시하고 variant 이름(`colorType-holiday`, `boxType-realtimeWorkActive`)만 봅니다.
- **반차처럼 하루의 일부만 인정되는 항목은 그 날을 통째로 제외합니다.** 칩에 `4:00`이 들어오면 남은 근무일에서 빠지므로, 실제로는 그날 절반을 더 일할 수 있는데도 하루 필요시간이 다소 크게(안전한 방향으로) 나옵니다.
- 시간 단위 휴가(시간차)는 근무시간에 합산되어 칩에 들어오므로 별도 처리가 없습니다. 그 날은 정상 근무일로 셉니다.
- 근태 항목 라벨(`연차` 등 텍스트)은 캘린더 행에 렌더되지 않는 것으로 확인됐습니다. 그래서 라벨이 아니라 칩 시간으로 판정합니다. 칩에 시간을 얹지 않는 종류의 휴가가 있다면 감지되지 않습니다.
- 진행 중인 오늘 근무는 위젯의 실근무/잔여 필수 시간에 반영되지 않습니다(퇴근 후 반영). 그래서 근무 중에는 표시값이 실제보다 약간 크게(안전한 방향으로) 나옵니다.
